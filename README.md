# Lab_TRPO

Учебный проект по дисциплине «Технологии разработки программного обеспечения».
Простой калькулятор на C++ (класс `Math`) с модульными тестами и CI/CD на GitHub Actions.

## Структура проекта

| Файл | Назначение |
|------|------------|
| `math.h`, `math.cpp` | Класс `Math` с арифметическими операциями |
| `main.cpp` | Демонстрационная программа |
| `tests/test_math.cpp` | Модульные тесты |
| `.github/workflows/main.yml` | Конфигурация CI/CD |
| `Doxyfile` | Настройки генерации документации |
| `VERSION`, `CHANGELOG.md` | Номер версии и история изменений |

## Сборка и запуск

```
g++ -std=c++17 -Wall -o app main.cpp math.cpp
./app
```

## Тесты

```
g++ -std=c++17 -Wall -o test_math tests/test_math.cpp math.cpp
./test_math
```

## CI/CD

При каждом push и Pull Request в GitHub Actions:
1. собирается программа и тесты, запускаются тесты (задание `test`);
2. Pull Request в `main` автоматически сливается, если тесты прошли (задание `automerge`);
3. генерируется HTML-документация Doxygen и сохраняется как артефакт `api-docs` (задание `docs`).

Локально документацию можно сгенерировать командой `doxygen Doxyfile` (результат в папке `docs/html`).

## Ветви

- `main` — стабильная версия;
- `development` — разработка новых функций;
- `release` — подготовка выпуска (теги `vX.Y.Z`).
