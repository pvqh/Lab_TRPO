# Lab_TRPO

Учебный репозиторий для лабораторной работы № 1 (Git). Приложение на C++ состоит из файлов `main.cpp`, `math.cpp`, `math.h`.

## Алиасы Git (вариант 6)

Алиасы добавлены в секцию `[alias]` файла `~/.gitconfig`.

| Алиас        | Команда                                         | Назначение                                      |
|--------------|-------------------------------------------------|-------------------------------------------------|
| `git st`     | `git status -sb`                                | Краткий статус с информацией о ветке            |
| `git ci`     | `git commit`                                    | Создание коммита                                |
| `git co`     | `git checkout`                                  | Переключение веток / файлов                     |
| `git br`     | `git branch`                                    | Список веток                                    |
| `git lg`     | `git log --oneline --decorate --all --graph`    | Граф истории всех веток                         |
| `git recent` | `git log --oneline -n 5`                        | Пять последних коммитов                         |

Алиас `git df` (`git diff`) был создан, проверен и затем удалён в рамках задания.

Как добавить алиас: `git config --global alias.<имя> "<команда>"`,
как удалить: `git config --global --unset alias.<имя>`.
